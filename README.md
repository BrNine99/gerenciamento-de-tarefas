# Gerenciador de Tarefas — CRUD com API REST

Projeto desenvolvido para praticar o ciclo de vida de requisições HTTP utilizando JavaScript e Fetch API.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- API REST (Fake API)
- Postman
- Git e GitHub

## Funcionalidades

- **GET:** Listar tarefas cadastradas.
- **POST:** Adicionar novas tarefas.
- **DELETE:** Excluir tarefas existentes.

## Como executar

1. Clone o repositório.
2. Abra o projeto no VS Code.
3. Configure a URL da API no arquivo `script.js`.
4. Execute o `index.html` utilizando o Live Server.

## ⚠️ Configuração da API

**Antes de executar o projeto, é necessário configurar a URL da API no arquivo `script.js`.**

O projeto pode utilizar qualquer API REST compatível com as operações implementadas.

Substitua os endereços utilizados nas requisições `fetch()` pela URL dos endpoints da API escolhida.

**Importante:** a API deve permitir requisições do navegador (CORS), oferecer suporte aos métodos HTTP utilizados e retornar os dados no formato esperado pela aplicação.

## Objetivo do projeto

Praticar o consumo de APIs REST, métodos HTTP, operações assíncronas, Promises, manipulação do DOM e tratamento de respostas e erros.
